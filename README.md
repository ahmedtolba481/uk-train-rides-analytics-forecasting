# UK Train Rides Analytics & Revenue Forecasting Dashboard

A comprehensive **Power BI data analytics and forecasting project** focused on analyzing UK train journeys, passenger demand, revenue performance, ticket classes, delays, and cancellations.

The project transforms raw railway transaction data into actionable business insights through **data cleaning, exploratory analysis, KPI development, interactive dashboards, and demand forecasting**.

The final solution provides decision-makers with insights into historical railway performance and forecasts the expected number of rides and daily revenue for the upcoming month.

## Project Objective

The main objective of this project is to use data analytics to answer important business questions related to railway operations, customer demand, and revenue generation.

The project focuses on:

* Understanding passenger journey patterns
* Analyzing revenue performance
* Identifying high-demand routes and periods
* Comparing ticket classes and customer demand
* Evaluating delays and cancellations
* Identifying operational trends and performance issues
* Forecasting the number of rides for the following month
* Forecasting daily revenue for the following month
* Estimating expected demand across different ticket classes
* Providing actionable insights to support business decision-making
